# Transkriptorius

Kalbos ir pokalbių transkribavimas realiu laiku su vertimu. Įdiegiama žiniatinklio programa (PWA): veikia kompiuteryje (Chrome, Edge), Android ir iPhone telefonuose.

- Nemokamas režimas – naršyklės kalbos atpažinimas.
- Profesionalus režimas – OpenAI (reikia naudotojo API rakto, jis saugomas tik naudotojo įrenginyje).
- Garso nustatymai: mikrofono pasirinkimas, garsumas, triukšmo filtras.
- Teams / Zoom pokalbio garso užrašymas (kompiuteryje).
- Eksportas: Word, TXT, SRT.

Programoje nėra jokių slaptažodžių ar raktų. Įrašai ir tekstai į šią saugyklą nepatenka.

Duomenų apsauga: prieš įrašydami pokalbį informuokite dalyvius ir gaukite jų sutikimą.
